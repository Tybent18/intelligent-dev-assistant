# From Developer Assistant to Obsidian

Obsidian is not a replacement pasted over an unrelated repository. It is the next architectural form of the experiments already present here.

## Progression map

| Earlier work | Capability explored | Obsidian destination |
|---|---|---|
| `basic_assist.py` | Speech input and text-to-speech | Voice shell |
| `adv_assist.py` | Multi-language execution and assistant orchestration | Developer command core |
| `debugging_assistant/` | Syntax checks, error capture, GUI debugging, generated-fix prompts | Diagnostic chamber |
| `RL_prototype/` | State, action, reward, and agent-environment loops | Future adaptation laboratory |
| `deep_RL_agent/` | Actor/critic scaffolding and training-loop experiments | Archived research toward adaptive policies |
| `flask_dashboard_agent/` | Browser-accessible assistant state | HoloLab web transport |
| `full_assist_RL_agent/` | Historical state and demand prediction | Future memory and prioritization layer |
| `proto_nano_assistant/` | Early browser assistant interface | Spatial console ancestry |
| `intermediate_nano_assistant/` | Recommendations and richer chatbot UI | Project intelligence panels |
| `nano_swarm_assistant/` | Laboratory and multi-agent simulation | HoloLab and future swarm chamber |

## Honest boundary

The earlier repository contains real prototypes and architectural experiments. It does not establish completed reinforcement learning, autonomous self-improvement, or a production-ready intelligent assistant. Obsidian preserves those artifacts as lineage while moving the actively supported path into a tested local core and visual laboratory.

## Version progression

1. **Assistant scripts** — speech, responses, execution, and basic reasoning utilities.
2. **Debugging tools** — specialized analysis and developer support.
3. **Learning experiments** — prototype environment and actor/critic structures.
4. **Web and nano interfaces** — browser control surfaces and laboratory simulations.
5. **Obsidian Stage One** — unified local assistant core with a screen-based holographic HoloLab.
6. **Future spatial layer** — WebXR, gesture input, tracked displays, or physical projection hardware.
